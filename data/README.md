# Local data folders

Large data files are intentionally not stored in Git.

- `gamus_raw/`: downloaded GAMUS dataset.
- `checkpoints/`: model weights.
- `inputs/`: images supplied for a run.
- `outputs/`: generated rasters, meshes, and previews.
- `references/`: LiDAR, GCP, or other comparison data.
- `sentinel2_dehradun/`: optional local demo inputs if you download them.

Read the main setup guides for download commands.
